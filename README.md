# CTO: Save the Company (AI Time Loop Game)

Un juego 2D de desplazamiento lateral (side-scroller) desarrollado con **Phaser 3** y **Vite**.

## 🎮 Descripción del Juego

En **CTO: Save the Company**, asumes el rol del Director de Tecnología (CTO) de una empresa de desarrollo de software en una jornada crítica. Tu objetivo es coordinar la transformación tecnológica de la compañía e incrementar la adopción de Inteligencia Artificial al 100% antes de que el reloj marque las 5:00 PM.

Explora las distintas áreas de la oficina, gestiona recursos y optimiza los procesos de tu equipo. Si la jornada laboral termina sin lograr la meta de adopción tecnológica, quedarás atrapado en un bucle temporal y tendrás que volver a intentarlo acumulando experiencia en cada iteración.

## 🏢 Zonas de la Oficina

1. **CTO Office**: Diseña la hoja de ruta de IA en la pizarra y audita los repositorios de código en tu portátil.
2. **Dev Bay**: Capacita a los desarrolladores en el uso de asistentes de IA (AI Copilot) y recarga energías en la máquina de café.
3. **Server Room**: Despliega un clúster local de nodos de GPU para acelerar los modelos de IA.
4. **Boardroom**: Presenta los resultados y el retorno de inversión (ROI) al CEO para consolidar el éxito de la empresa.

## ⌨️ Controles

* **Moverse a la izquierda / derecha**: Teclas `A` / `D` o Flecha Izquierda / Flecha Derecha.
* **Interactuar**: Tecla `E` (al acercarse a un objeto o personaje interactivo).
* **Iniciar / Reiniciar Bucle**: Teclas `Espacio` / `R`.

## 🛠️ Instalación y Desarrollo

Asegúrate de tener [Node.js](https://nodejs.org/) instalado en tu sistema.

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Previsualizar la compilación de producción
npm run preview
```

## 🚀 Tecnologías Utilizadas

* **Phaser 3**: Motor de videojuegos 2D para la web.
* **Vite**: Herramienta de compilación y servidor de desarrollo rápido.
* **JavaScript (ES Modules)**
